# Satellite-Telemetry
This satellite telemetry is a simultion software of the satallite which shows the 3D representation of satellite object to show the reprasentation of the gyroscopoic work on satellite using ESP32 and a web server.

# STEPS TO PERFORM THIS :
1. Download this folder from git-hub;
2. Extract the downloaded zip file.
3. Download littleFs by using chatgpt that provide github link
4. After the download of littleFs file add it into the the aurduino file as instructed .
5. Compile the aurduino code and find the IP Address
6. Run the IP address in web server , by HTTP sharing you obtain the gyro result of satllite movement.
